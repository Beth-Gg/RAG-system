# PRM Tool User Manual

## Purpose

Welcome to the PRM training manual. This document will guide you through the features, functionalities, and processes involved in using the PRM Tool easily and effectively.

## What is PRM?

PRM tool is designed to capture and manage participant data efficiently. It stores personal and business information for participants and enterprises, tracks each participant's training status, and provides dynamic reporting capabilities.

The tool supports two types of users:

- **Admin Users**: Admin users have special rights and privileges, allowing them to create and delete regular users within the organization.
- **Regular Users**: Regular users have standard access to the tool’s features.

## Getting Started

### 1. Accessing the Tool

- Navigate to [PRM Login Page](https://icipe.vercel.app/) (Best used with Google Chrome)
- Enter your username and password
- Click **Sign in**

![Login Page](prm_images/prm_page2_img1.png)

### 2. Dashboard View

Upon logging in, you will see the main dashboard, which includes different sections of the tool.

![Dashboard](prm_images/prm_page3_img1.png)

## Core Features

### 1. Adding Participants

1. Select **"Add participant"**.

   ![Add Participant Button](prm_images/prm_page4_img1.png)

2. Fill out the necessary participant information and click **"Submit"**.

   ![Participant Form](prm_images/prm_page5_img1.png)

3. Continue filling out participant details and click **"Save"**.

   ![Save Participant](prm_images/prm_page5_img2.png)

4. Click **"Employment"** and enter employment information, then **"Save"**.

   ![Employment Details](prm_images/prm_page5_img3.png)

5. Click **"Finance"**, enter financial information, and **"Save"**.

   ![Finance Information](prm_images/prm_page6_img1.png)

6. Click **"Geography"** to add geographical data, fill in the fields, and **"Save"**.

   ![Geographical Data](prm_images/prm_page6_img2.png)

7. Click **"Technology"**, enter technology familiarity, and **"Save"**.

   ![Technology Familiarity](prm_images/prm_page6_img3.png)

### 2. Adding Business Details

1. Select **"Business"** on the participant detail page.

   ![Business Details](prm_images/prm_page7_img1.png)

2. Populate the business fields and click **"Save"**.

   ![Save Business Info](prm_images/prm_page7_img2.png)

### 3. Creating Groups/Enterprises

1. Select **"Groups"** from the list.

   ![Groups Page](prm_images/prm_page7_img3.png)

2. Click **"Add Group"** on the top right corner.

   ![Add Group](prm_images/prm_page8_img1.png)

3. Fill out group information and click **"Save"**.

> **Note**: The **Group Representative** dropdown pulls names from registered participants.  
> If the representative's profile includes business details, these will automatically populate.

### 4. Adding/Removing Members from Groups

1. To add members, go to the group and click **"Add Members"**.

   ![Add Members](prm_images/prm_page9_img1.png)

2. Check the box next to each participant you want to add and select **"Add to Group"**.

   ![Select Members](prm_images/prm_page9_img2.png)

3. Click **"View Members"** to see added members.

   ![View Members](prm_images/prm_page10_img1.png)

4. To remove a participant, click **"View Members"**, select the participant, and click **"Remove from Group"**.

   ![Remove Members](prm_images/prm_page11_img1.png)

### 5. Creating Users

1. Select **"Users"** from the sidebar.

   ![Users Page](prm_images/prm_page12_img1.png)

2. Click **"Add Users"**.

   ![Add Users](prm_images/prm_page12_img2.png)

3. Populate user information and click **"Save"**.

   ![Save User](prm_images/prm_page12_img3.png)

## Field Descriptions

### Participant Details

| **Field Name**            | **Description** |
|---------------------------|----------------|
| First Name                | Participant's first name |
| Father Name               | Participant's father's name |
| Grandfather Name          | Participant's grandfather's name |
| Date of Birth             | Participant's date of birth |
| Gender                    | Participant's gender |
| Education Level           | Highest education level attained |
| Marital Status            | Participant's marital status |
| Phone                     | Primary phone number |
| Secondary Phone           | Secondary phone number |
| Disability Status         | Whether the participant has a disability |
| IDP                       | Whether the participant is internally displaced |
| Refugee                   | Whether the participant is a refugee |
| Household Men             | Number of men in the household |
| Household Women           | Number of women in the household |
| Dependents Without Job    | Number of unemployed dependents |
| High School Graduates     | Number of high school graduates in the household |
| Employment Status         | Whether the participant is employed |
| Type of Employment        | Type of employment if employed |
